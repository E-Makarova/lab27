# lab27
Название проекта: events — афиша мероприятий Новосибирск

## Описание назначения
Веб-приложение с афишей культурных и развлекательных мероприятий Новосибирска (концерты, спектакли, выставки, кино).

## Список участников
* Шуйская Анастасия
* Макарова Эвелина

## Что нужно реализовать
* Главную страницу с шапкой, блоком фильтров, сеткой карточек и подвалом (`index.html`).
* Адаптивную сетку и базовые стили оформления (`main.css`, `components.css`).
* Локальную базу мероприятий Новосибирска (название, дата, площадка, цена, категория, постер, описание) в виде массива объектов (`data.js`).
* Динамическую отрисовку карточек мероприятий на странице (`render.js`).
* Фильтрацию мероприятий по категориям без перезагрузки страницы (`filter.js`).
* Модальное окно с подробным описанием события при клике на карточку.

## Используемые технологии
* HTML
* CSS
* JS

## Инструкция по запуску
1. Склонируйте репозиторий на компьютер:
   ```bash
   git clone https://github.com/E-Makarova/lab27.git
   ```
2. Откройте папку `events`.
3. Запустите файл `index.html` в любом браузере (или через Live Server в VS Code).

## Правила участия в разработке
1. **Не пушить напрямую в `main`** — там хранится только готовая рабочая версия.
2. **Вся работа ведется через ветку `dev`** и отдельные ветки под каждую задачу (например, `feature/filters`, `feature/cards-style`).
3. **Слияние через Pull Request** — перед тем как влить ветку в `dev`, второй участник проверяет код и подтверждает изменения.
4. **Понятные коммиты** — каждое изменение подписывается коротко и по сути.
